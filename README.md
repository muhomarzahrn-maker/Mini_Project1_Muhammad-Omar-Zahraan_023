PENJELASAN PROGRAM: 

Program ini merupakan sistem pengelolaan data sederhana yaitu Sistem Booking Lapangan Futsal & Mini Soccer, dimana mengombinasikan list dan juga tuple didalamnya. Pada program ini menyediakan 5 pilihan menu, yaitu;
1. Booking Lapangan, dimana kita bisa menyimpan data kita sebagai pelanggan yang akan memesan lapangan.
2. Tampilkan Semua Booking, dimana kita bisa melihat list siapa saja yang melakukan pemesanan lapangan.
3. Ubah Data Booking, dimana kita bisa mengubah data pemesanan lapangan yang sudah kita lakukan sebelumnnya.
4. Hapus Data Booking, dimana kita bisa menghapus data pemesanan lapangan yang sudah kita lakukan sebelumnya.
5. Keluar.

Tujuan dari program ini adalah untuk mempermudah pengelolaan sistem booking lapangan futsal & mini soccer, dimana pengelola dapat dengan mudah untuk menambah, mengubah, dan menghapus jadwal booking lapangan dengan cepat. Selain kemudahan akses data bagi pengelola, juga meminimalisir human error dan membuat operasional menjadi lebih fleksibel, serta memberikan transparansi pembayaran.
